# RFA_module — 외부게시 MCP Agent

NVIDIA Agentic AI 해커톤 팀 프로젝트(개인 비서 멀티에이전트)의 한 모듈.
외부 채널(GitHub 등)에서 온 요청을 받아 → 실무대장에게 지식을 요청 → 언론사가 초안 작성 → 기밀검토 → 사람 결재 → 외부 채널에 게시한다.
