# Public 채널 공식 기밀 기준

대외 공식 기밀관리 기준. 공개 GitHub 등 누구나 볼 수 있는 곳에 나가는 글에 적용한다.
사람이 거절한 사례(feedback)로 계속 보완한다.

## 규칙
- [release-date] 출시·릴리즈 예정일은 공식 발표 전까지 비공개. 대체 표현: "일정은 확정되면 공유드릴게요".
- [model-name] 미공개 모델 코드명(Nimbus2 등)은 비공개. 대체: "차기 모델".
- [internal-metric] 내부 벤치마크 수치(EM, 지연, 정확도 등)는 비공개. 대체: "소폭 하락/개선" 수준의 정성 표현.
- [roadmap] 아직 결정되지 않은 향후 계획은 비공개.
- [infra] 사내 서버 주소, 저장소 경로, 토큰, 계정 정보는 비공개. 대체 없이 삭제.

## 허용
- 공개 논문에 있는 방법론과 수치.
- 공개 레포 링크, 공개 문서 링크.
